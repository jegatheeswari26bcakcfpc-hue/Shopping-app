# Shopping Cart Flow

##  Project Overview

This project represents a complete **Shopping Cart Flow** for an e-commerce mobile application.  
The flow shows how a user can browse products, add items to the cart, complete checkout, and track the order.

##  User Flow

1. **Home / Shop Screen**
   - Browse products
   - Search for products
   - View categories and best sellers

2. **Product Details**
   - View product image
   - Select color and size
   - Add product to cart

3. **Cart Screen**
   - View selected products
   - Increase or decrease quantity
   - Remove products
   - View total amount
   - Proceed to checkout

4. **Delivery Address**
   - Select saved address
   - Edit address
   - Add a new delivery address

5. **Payment Method**
   - UPI
   - Credit / Debit Card
   - Net Banking
   - Cash on Delivery

6. **Order Summary**
   - View items
   - Apply coupon
   - Check delivery charges
   - View total amount
   - Place order

7. **Order Processing**
   - Order is being processed
   - Payment and order details are confirmed

8. **Order Confirmation**
   - Order successfully placed
   - View order details
   - Continue shopping

9. **Track Order**
   - View order status
   - Order placed
   - Packed
   - Out for delivery
   - Delivered

10. **My Orders**
   - View all orders
   - Check delivery status
   - View previous orders

##  Objective

The main objective of this project is to design a **simple, clear, and user-friendly shopping cart experience** from product selection to successful order delivery.

##  Tools Used

- Prototyping

##  Key Features

- Order history
